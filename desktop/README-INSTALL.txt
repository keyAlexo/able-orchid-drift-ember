Писание — Библия для macOS 12 Monterey
=====================================

Как установить
--------------
1. Откройте этот диск (двойной щелчок по файлу .dmg, если он ещё не открыт).
2. Перетащите «Писание» в папку «Программы» (Applications).
3. При первом запуске: щёлкните приложение правой кнопкой (или Control-клик)
   и выберите «Открыть». Подтвердите запуск.

   Так нужно сделать один раз: приложение не подписано аккаунтом Apple
   Developer, поэтому Gatekeeper спрашивает разрешение.

Apple Silicon (M1 / M2)
-----------------------
Сборка рассчитана на Intel и на Apple Silicon через Rosetta.
Если система предложит установить Rosetta — согласитесь.

Как пользоваться
----------------
• Слева — все книги Библии (синодальный перевод, текст на компьютере, без сети).
• Нажмите стих — он выводится на панель «Второй экран».
• Кнопка «Второй экран» открывает отдельное окно; перетащите его
  на второй монитор или оставьте рядом. Основное окно по-прежнему
  показывает всю Библию.

Сочетания клавиш: стрелки и J/K — стихи, [ ] — главы, Enter — на экран,
Cmd+K — поиск.

Перевод: Синодальный, общественное достояние.
